Windows 使用指南

用手机触控板和键盘控制 Windows 电脑

HostTap 可让你在手机上移动 Windows 电脑的指针、点击、滚动和输入文字。让手机与 Windows 接收器配对后，就能用手机操控电脑屏幕上的内容。

需要准备什么

  • 从 Microsoft Store 获取 HostTap Windows 版。
  • 在手机上安装 HostTap 安卓版，或使用包含 HostTap 遥控功能的 iPhone 版 KeyTrans。
  • 手机和电脑之间需要有可用的网络连接路径。HostTap 不使用云中继。

将手机与 Windows 电脑配对

  1. 在 Windows 电脑上安装并打开 HostTap。
  2. 在 Android 上打开 HostTap，或在 iPhone 上打开 KeyTrans，然后选择扫描二维码。
  3. 扫描 Windows 接收器显示的配对码，并在手机应用中确认这台电脑。
  4. 用触控区域移动指针和点击；需要输入文字时，打开手机键盘。

首次扫描时按系统提示授予相机权限。配对码只用于你的设备，请勿分享截图或复制出来的配对信息。

手机无法连接时

配对时让两端应用保持打开，并确认手机和电脑可以通过当前网络互相访问。访客 Wi-Fi、设备隔离或防火墙规则可能阻止设备互连；HostTap 没有云中继来绕过这些限制。

如果配对已完成但输入没有到达电脑，请切回 Windows 接收器，并确认目标输入框已获得焦点。

获取 HostTap

在官网下载 Windows 接收器，并选择 Android 或 iPhone 配套应用。
