开始使用

安装 HostTap，并将手机与电脑配对

HostTap 由电脑接收器和手机配套应用组成。扫描接收器显示的二维码完成配对，然后就能用手机触控板和键盘控制电脑。

开始前准备

  • 从官网下载页面安装 Windows 或 Mac 接收器。
  • 在 Android 上安装 HostTap，或在 iPhone 上使用包含 HostTap 控制功能的 KeyTrans。
  • 确保手机和电脑可以通过当前网络互相访问。HostTap 不使用云中继。

配对设备

  1. 打开电脑接收器，并保持配对二维码页面可见。
  2. 打开手机应用并选择扫描二维码；首次使用时按提示授予相机权限。
  3. 扫描接收器上的配对码，然后在手机应用中确认这台电脑。
  4. 用触控区域移动指针；需要输入文字时，打开手机键盘。

配对码和链接用于连接你的设备。请勿公开发布，也不要通过邮件发送给客服。

连接问题排查

  • 无法扫描二维码：检查手机相机权限，擦拭镜头，并确保接收器二维码完整可见。
  • 扫描后无法连接：确认两端应用已打开，且网络允许手机与电脑互相访问。访客 Wi-Fi 和设备隔离可能会阻止连接。
  • 配对成功但没有输入：检查电脑上是否有权限提示，并确认目标输入框已获得焦点。

HostTap 不提供云中继。设备能否连接取决于网络路由和防火墙设置。
