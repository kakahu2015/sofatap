Getting started

Set up HostTap and pair your phone with a computer

HostTap uses a computer receiver and a phone companion app. Pair them with the QR code shown by the receiver, then use the phone as a touchpad and keyboard.

Before you start

  • Install the HostTap receiver for Windows or Mac from the downloads page.
  • Install HostTap on Android or use KeyTrans on iPhone; KeyTrans includes HostTap controls.
  • Make sure the phone and computer can reach each other over the network. HostTap does not use a cloud relay.

Pair your devices

  1. Open the receiver on the computer and leave its pairing screen visible.
  2. Open the phone app and choose its QR scanning option. Allow camera access if requested.
  3. Scan the code on the receiver, then confirm the computer in the phone app.
  4. Move the pointer with the touch surface. Use the phone keyboard when you need to enter text.

Pairing codes and links are for your devices. Do not post them publicly or send them to support.

Troubleshoot a connection

  • The code will not scan: check camera access, clean the camera lens, and keep the receiver's QR code unobstructed.
  • The phone scans but cannot connect: confirm both apps are open and the network allows the phone and computer to communicate. Guest Wi-Fi and device isolation can block this.
  • Pairing works but input does not: check for a computer permission prompt and make sure the intended text field is focused.

HostTap does not operate a cloud relay. Whether two devices can connect depends on the network route and its firewall settings.

Platform-specific instructions

See the Windows phone touchpad and keyboard guide or the Mac phone touchpad and keyboard guide for receiver downloads and platform notes.
