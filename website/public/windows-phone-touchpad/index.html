Windows setup

Use your phone as a touchpad and keyboard for Windows

HostTap lets you move the pointer, click, scroll and type on a Windows computer from your phone. Pair the phone with the HostTap receiver, then keep the computer display where you can see it.

What you need

  • HostTap for Windows from the Microsoft Store.
  • The HostTap Android app or KeyTrans for iPhone, which includes HostTap controls.
  • A network route that lets the phone and computer reach each other. HostTap does not use a cloud relay.

Pair a phone with a Windows computer

  1. Install and open HostTap on the Windows computer.
  2. Open HostTap on Android or KeyTrans on iPhone, then choose the QR scanning option.
  3. Scan the pairing code shown by the Windows receiver and confirm the computer in the phone app.
  4. Use the touch surface to move and click the pointer. Open the phone keyboard when you want to type.

Allow camera access when the phone asks to scan the code. The pairing code is private to your devices, so do not share a photo or copy of it.

If the phone cannot connect

Keep both apps open while pairing and check that the phone and PC can communicate over the network. Guest Wi-Fi, device isolation, or a restrictive firewall can prevent devices from reaching each other. HostTap has no hosted relay to work around those network restrictions.

If pairing completed but input does not arrive, bring the Windows receiver to the foreground and check that the intended text field is focused.
