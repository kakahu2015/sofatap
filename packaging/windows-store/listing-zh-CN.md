## 产品名称

HostTap Remote

## 简短说明

把 iPhone 变成 Windows 电脑的无线鼠标、键盘和文字输入遥控器。

## 详细描述

HostTap Remote 让 iPhone 成为电脑的鼠标和键盘。坐在沙发上就能操作客厅里的 Windows 电脑，不需要额外的键鼠或触控板。

在电脑上安装接收端、在 iPhone 上打开 HostTap 应用、扫描接收端窗口里的二维码即可连接。数据只在你自己的局域网内传输：没有账号、无需登录、不经过云端中转。

可以做什么

- 在手机界面上移动指针、单击、双击、拖拽和滚动。
- 用手机键盘输入文字，支持系统听写，发送前可以检查并修改。
- 下次连接已保存的电脑时无需重新扫码。
- 电脑继续使用自己的屏幕显示，接收端不做屏幕镜像或串流。

如何使用

1. 安装并打开 HostTap Remote，窗口会显示二维码和本机监听地址。
2. 在 iPhone 上选择「扫描二维码」，对准接收端窗口。
3. 确认电脑名称后即可开始控制。

不支持什么

- 不提供屏幕串流、录屏或远程桌面。
- 没有无人值守自动操作，每一次操作都来自正在使用的手机。
- 不解锁锁屏，不绕过 Windows Hello。

运行要求

- Windows 10 1809 或更高版本，x64 或 arm64。
- iPhone 上安装 HostTap 应用，并与电脑处于同一局域网。
- 两台设备需在同一可达的家庭或办公网络中。

隐私

配对凭据仅保存在本机，不收集账号信息，不向服务器发送遥测数据。详情见隐私政策。
